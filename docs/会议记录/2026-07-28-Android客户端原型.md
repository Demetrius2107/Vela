### Android 客户端原型

| 模块 | 说明 |
|------|------|
| `android/` 项目结构 | Kotlin + Jetpack Compose + Gradle 8.5 + compileSdk 34 |
| 网络层 | Retrofit API 接口（登录/注册/发送消息/离线同步）+ OkHttp WebSocket |
| 登录/注册 | Compose UI + AuthViewModel + SharedPreferences Token 持久化 |
| 主页会话列表 | LazyColumn + 在线状态/未读数/消息预览 |
| 聊天界面 | 消息气泡（左右区分）/输入框/发送按钮/自动滚屏 |
| 通讯录 | 联系人列表 + 在线状态绿点 |
| 设置 | 账号信息/通知/关于/退出登录 |
| 导航 | NavHost 串联 login → home → chat/contacts/settings |

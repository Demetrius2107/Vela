## 当前项目结构

```
Vela/
├── vela-gateway/        ← 新增：API 网关
├── vela-service/        ← 后端业务服务

├── vela-message-store/  ← 消息存储
├── vela-common/         ← 共享内核
├── vela-codec/          ← 编解码

│   │   ├── api/         ← 请求层
│   │   ├── stores/      ← 状态管理层
│   │   ├── utils/       ← 工具层
│   │   ├── components/  ← 组件层

│   └── ...
├── deploy/              ← 新增：部署配置
├── docs/
│   ├── guide/           ← Docker 指南文档
│   └── 会议记录/         ← 新增：会话工作记录
└── docker-compose.yml   ← 含网关+监控+前端
```

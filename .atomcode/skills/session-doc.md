# 会话工作记录 Skill

> 每次会话结束时自动调用，生成 Markdown 文档到 `docs/会议记录/` 目录。
> 调用方式：`use_skill("session-doc")`

## 使用时机

在每次会话的**最后一步**调用，生成本次会话的工作记录文档。

## 文档输出规范

### 文件路径
```
docs/会议记录/YYYY-MM-DD-<主题>.md
```

### 文档模板

```markdown
# Vela IM — 会话工作记录

> 日期：YYYY-MM-DD
> 分支：<当前分支>
> 状态：开发进行中 / 阶段完成 / 已合并

---

## 本次完成工作

### 1. <功能模块1>

| 文件/模块 | 改动说明 |
|-----------|----------|
| `path/to/file` | 做了什么 |

### 2. <功能模块2>
...

## Git 提交记录

```
<git log 当前分支相对于 master 的新提交>
```

## 当前项目状态

- 分支领先 master X 个提交
- 待合并/已合并

## 待办事项

| 优先级 | 事项 | 状态 |
|:------:|------|:----:|
| 🔴 | 紧急事项 | ⏳ |
| 🟡 | 后续事项 | 📋 |
| 🟢 | 远期事项 | 📋 |

---

> 文档版本: v1.0 | 创建时间: YYYY-MM-DD
```

## 执行步骤

1. 检查当前分支：`git branch --show-current`
2. 获取分支领先 master 的提交：`git log --oneline master..HEAD`
3. 汇总本次会话所有改动（修改/新增的文件）
4. 按模板生成文档
5. 保存到 `docs/会议记录/YYYY-MM-DD-<主题>.md`
6. `git add` 并 `git commit -m "docs: 会话工作记录——<主题>"`

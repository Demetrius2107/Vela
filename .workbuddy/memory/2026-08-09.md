## 2026-08-09

### importUser / importFriendShip 幂等性修复
- **问题**：重复运行 Phase 1 测试脚本时，user 和 friendship 服务的 import 接口直接 INSERT 导致 DuplicateKeyException
- **根因**：`ImUserServiceImpl.importUser()` 和 `ImFriendServiceImpl.importFriendShip()` 用 `mapper.insert()` 无脑插入，虽然 catch 了异常但 `e.printStackTrace()` 输出大量错误日志
- **修复**：插入前用 QueryWrapper 查是否存在，存在则跳过并放入 successId
- **影响文件**：
  - `vela-service-user/.../ImUserServiceImpl.java` — importUser 方法加存在性检查
  - `vela-service-friendship/.../ImFriendServiceImpl.java` — importFriendShip 方法加存在性检查

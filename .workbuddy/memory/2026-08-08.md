### 修复 Spring Boot 多模块打包冲突

**问题**：微服务模块（user/friendship/conversation/message 等）都有 `spring-boot-maven-plugin`，打包时 repackage 用 fat jar 替换原始 jar。其他模块依赖它们时找不到类（类在 `BOOT-INF/classes/` 下）。

**修复**：给 12 个模块的 `spring-boot-maven-plugin` 添加 `<classifier>exec</classifier>`：
- vela-message-store / vela-service-user / vela-service-friendship / vela-service-conversation
- vela-service-message / vela-service-group / vela-service-bot / vela-service-admin
- vela-service-config / vela-service-knowledge / vela-service-office / vela-gateway
- vela-common 不需要（已有 `<skip>true</skip>`）

**效果**：原始 jar 保留给其他模块依赖，`-exec.jar` 用于运行服务。`mvn clean package -DskipTests` 全部 17 模块 BUILD SUCCESS（8分36秒）。

### 修复 SnakeYAML 版本不兼容

**问题**：Gateway 启动报 `NoSuchMethodError: org.yaml.snakeyaml.constructor.SafeConstructor: method 'void <init>()' not found`。根因：父 pom.xml 中 `<snakeyaml.version>2.0</snakeyaml.version>` 覆盖了 Spring Boot 2.3.2 默认的 1.24。SnakeYAML 2.0 删除了 `SafeConstructor()` 无参构造器。

**修复**：将 `<snakeyaml.version>` 从 `2.0` 改为 `1.24`。

### 修复 Gateway DataSource 自动配置冲突

**问题**：Gateway 启动报 `Failed to determine a suitable driver class`。根因：父 pom 把 `mybatis-plus-boot-starter` 和 `mysql-connector-java` 放在 `<dependencies>` 而非 `<dependencyManagement>`，所有模块被强制引入。Gateway 不需要数据库，但 Spring Boot 检测到 classpath 有 MySQL 驱动就尝试自动配置 DataSource。

**修复**：在 `GatewayApplication.java` 添加 `@SpringBootApplication(exclude = {DataSourceAutoConfiguration.class, DataSourceTransactionManagerAutoConfiguration.class, MybatisPlusAutoConfiguration.class})`

### 修复 @EnableFeignClients 缺失（项目级通病）

**问题**：Friendship 服务启动报 `NoSuchBeanDefinitionException: UserServiceFeignClient`。根因：所有 4 个有 Feign 客户端的服务 Application 类都缺少 `@EnableFeignClients` 注解，导致 Feign 接口不会被注册为 Spring Bean。

**受影响服务**：
- friendship → UserServiceFeignClient (调用 user:8010)
- group → MessageServiceFeignClient (调用 message:8014)
- user → GroupServiceFeignClient (调用 group:8012)
- message → GroupServiceFeignClient (调用 group:8012)

**修复**：4 个 Application 类均添加 `@EnableFeignClients` 注解和对应 import。

**次要问题（未修）**：`ImFriendShipEntity` 缺少 `@TableId` 注解，MyBatis-Plus 警告 "Can not find table primary key"。不影响启动，但 `selectById` 等操作会出问题。friendship 表可能使用联合主键（app_id + from_id + to_id）。

### 修复 scanBasePackages 漏扫 shared 包

**问题**：`ImServerProperties`（`@Component`, `@ConfigurationProperties(prefix="appconfig")`）在 `com.vela.im.shared.config` 包，但所有服务的 `scanBasePackages` 都只扫了自己的包和 `com.vela.im.service.common`，漏了 `com.vela.im.shared`。所有 `@Component` 在 shared 包的类（ImServerProperties、GlobalHttpClientConfig）对服务不可见。

**受影响服务**：friendship / user / message / group / conversation（5 个）

**修复**：5 个 Application 类 scanBasePackages 均添加 `"com.vela.im.shared"`
